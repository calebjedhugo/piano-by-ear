# corpus

`phrases.json` is generated by `scripts/build-corpus.mjs` from Humdrum
**kern editions by Craig Stuart Sapp:

- https://github.com/craigsapp/bach-370-chorales (soprano lines)
- https://github.com/craigsapp/mozart-piano-sonatas (right-hand lines)

Both are licensed CC BY-NC-SA 4.0, so this derived file is too:
https://creativecommons.org/licenses/by-nc-sa/4.0

Rebuild:

```bash
git clone --depth 1 https://github.com/craigsapp/bach-370-chorales /tmp/bach
git clone --depth 1 https://github.com/craigsapp/mozart-piano-sonatas /tmp/mozart
node scripts/build-corpus.mjs /tmp/bach/kern /tmp/mozart/kern
```
